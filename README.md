# Archery Spot — Feedback & Bug Reports

You're in the right place. This is the **official feedback tracker for the Archery Spot
app** — the one at **[www.archeryspot.app](https://www.archeryspot.app)**.

There's no app code here on purpose. This repo exists so you can report problems and
ideas without needing access to anything else.

## Report something

| | |
|---|---|
| 🐞 **Something's broken** | [Report a bug](https://github.com/vtajzich/archery-spot-feedback/issues/new?template=01-bug.yml) |
| 💥 **The app crashed / closed itself** | [Report a crash](https://github.com/vtajzich/archery-spot-feedback/issues/new?template=02-crash.yml) |
| 💡 **An idea, or something that just feels off** | [Send feedback](https://github.com/vtajzich/archery-spot-feedback/issues/new?template=03-feedback.yml) |

Before you file, have a quick look at the [open reports](https://github.com/vtajzich/archery-spot-feedback/issues)
— if someone already reported it, add a 👍 or a comment instead. That tells us how many
people it affects.

**Write in English or Czech, whichever you prefer.** Both are read.

## Include your app version

Open the app → **Settings → About**. It shows something like `2.4.1 (51)`. Copy it
exactly — the number in brackets tells us which build you're on, and that's usually the
difference between "we can find it" and "we can't".

## ⚠️ This page is public

Anything you write here — text, screenshots, logs — is visible to anyone on the internet
the moment you post it, and stays indexed even if it's deleted later. So:

- No e-mail addresses, real names, or account IDs
- Check screenshots before attaching them

For anything private — your account, a purchase, a password — write to
**info@archeryspot.app** instead. Don't open an issue.

## What happens next

Every report is read. Confirmed bugs move into the private development repo, and you'll
see the issue here get closed with a note when the fix ships. We can't promise timelines
— it's a small team.

Thanks for taking the time. A good bug report is genuinely the most useful thing you can
send us.
